# ProjectRabbs

ProjectRabs is a browser-based OC corkboard app for creating, customizing, and sharing original character profiles with images, stickers, themes, and a searchable feed. It includes profile personalization and community features.

## Pages

- `index.html` — original app
- `user.html` — user portal mockup
- `admin.html` — admin dashboard mockup

These are static front-end pages. The user and admin mockups do not currently have real authentication, protected admin access, or a shared backend.
